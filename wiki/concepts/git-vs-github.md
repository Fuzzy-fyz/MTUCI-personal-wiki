# Git и GitHub

## In one sentence

Git - система контроля версий
GitHub - сервис, в который мы выкладываем свои Git репозитории

## Explanation

Git - нужен нам для контроля версий в VsCode ( там есть даже отдельная плашка)

GitHub - нужен нам для того, чтобы работать в команде и брать этот репозиторий из любой точки мира

## Example

команда git init - создает git хранилище
потом нужна команда git add . чтобы зафиксировать все изменения в файле
после надо зафиксировать и создать комментарий командой git commit -m 'Тут пояснение'

## Boundaries and common mistakes

Git - система контроля версий, а вот GitHub - это то, где мы храним репозитории (Они разные)
